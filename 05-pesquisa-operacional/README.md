Pesquisa Operacional — LifeSync

Objetivo

Esta pasta reúne os documentos, modelos matemáticos e resultados dos problemas de otimização desenvolvidos no projeto acadêmico LifeSync.

Estrutura de arquivos

modelo-matematico.md: descrição dos problemas, variáveis de decisão, função objetivo e restrições.

otimizacao.ipynb: implementação dos modelos e resolução em Python.

dados-de-entrada.csv: dados utilizados nos cenários de otimização.

resultados.md: soluções obtidas, interpretação e conclusões.

Orientações

O trabalho deverá contemplar dois tipos de problema:

Maximização: encontrar a melhor solução para um objetivo, respeitando as restrições definidas.

Minimização: encontrar uma solução que reduza custos ou recursos utilizados, respeitando as condições do cenário.

Os dados e as hipóteses deverão ser documentados. Os resultados deverão ser conferidos e interpretados antes da entrega.

Status

Estrutura inicial criada. Os modelos e as análises serão desenvolvidos conforme as orientações da disciplina.
