# Análise de Dados — LifeSync

## Objetivo

Esta pasta reúne os arquivos, documentos e resultados relacionados à análise de dados do projeto acadêmico LifeSync.

O objetivo desta etapa é organizar, preparar e analisar dados do IBGE, identificando diferenças na proporção de pessoas com algum grau de pobreza e comparando as contribuições das seis dimensões do Índice de Pobreza Multidimensional Não Monetário (IPM-NM).

## Descrição dos arquivos

- **dados/originais:** contém a tabela original disponibilizada pelo IBGE.
- **dados/tratados:** contém a planilha organizada e o gráfico de comparação entre os estados.
- **documentação:** reúne a identificação da fonte dos dados e o dicionário de dados.
- **preparação:** apresenta o relatório com os procedimentos utilizados no tratamento dos dados.
- **analise-inicial.md:** apresenta os resultados, comparações entre as Unidades da Federação, interpretação das dimensões e conclusões iniciais.

## Fonte dos dados

Os dados utilizados são provenientes do Instituto Brasileiro de Geografia e Estatística (IBGE), referentes ao período de 2017–2018, conforme a Tabela 6b da publicação sobre a evolução dos indicadores não monetários de pobreza e qualidade de vida no Brasil.

**Origem:** dados reais e públicos.

## Metodologia

A análise foi desenvolvida a partir da organização e preparação da tabela original, seguida da comparação dos resultados entre as Unidades da Federação.

Foram analisadas as seis dimensões do IPM-NM, utilizando tabelas e gráficos para facilitar a interpretação dos resultados.
