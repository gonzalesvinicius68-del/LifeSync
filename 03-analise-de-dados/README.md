Análise de Dados — LifeSync

Objetivo

Esta pasta reúne os arquivos e resultados relacionados à análise de dados do projeto acadêmico LifeSync.

Conteúdo previsto

base-de-dados.csv: base de dados utilizada na análise.

analise.ipynb: notebook de análise desenvolvido em Python.

dicionario-de-dados.xlsx: descrição das variáveis e dos campos da base.

graficos/: gráficos produzidos durante a análise.

resultados.md: interpretação dos resultados e principais conclusões.

Orientações

A origem dos dados deverá ser identificada como real, pública ou simulada. As análises devem apresentar os métodos utilizados, os gráficos relevantes e as limitações encontradas.

O notebook deverá ser executado em ambiente compatível, como Google Colab ou Jupyter Notebook, conforme as orientações da disciplina.

Status

Estrutura inicial criada. Os arquivos serão adicionados conforme o desenvolvimento das atividades.
