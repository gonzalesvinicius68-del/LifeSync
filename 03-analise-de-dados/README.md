# Análise de Dados — LifeSync

## Objetivo

Esta pasta reúne os arquivos, documentos e resultados relacionados à análise de dados do projeto acadêmico LifeSync.

O objetivo desta etapa é organizar, preparar e analisar dados do IBGE, identificando diferenças na proporção de pessoas com algum grau de pobreza e comparando as contribuições das seis dimensões do Índice de Pobreza Multidimensional Não Monetário (IPM-NM).

## Descrição dos arquivos

- **dados/originais:** contém a tabela original disponibilizada pelo IBGE.
- **dados/tratados:** contém a planilha organizada para análise e o gráfico de comparação entre os estados.
- **documentacao:** reúne o dicionário de dados, a fonte dos dados e informações gerais sobre a documentação.
- **preparacao:** apresenta o relatório com os procedimentos utilizados na preparação dos dados.
- **analise-inicial.md:** apresenta os resultados, as comparações entre as Unidades da Federação, a interpretação das informações e as conclusões iniciais.

## Fonte dos dados

Os dados utilizados são provenientes do Instituto Brasileiro de Geografia e Estatística (IBGE), referentes ao período de 2017–2018, conforme a Tabela 6b da publicação sobre a evolução dos indicadores não monetários de pobreza e qualidade de vida no Brasil.

**Origem:** dados reais e públicos.

## Metodologia

A análise foi desenvolvida a partir da organização e preparação da tabela original, seguida da comparação dos resultados entre as Unidades da Federação.

Foram comparadas as contribuições das seis dimensões do IPM-NM, utilizando tabelas e gráficos para facilitar a interpretação dos resultados.

## Estado do desenvolvimento

Etapa de análise de dados em desenvolvimento, com organização das bases, documentação, preparação dos dados, visualização gráfica e análise inicial dos resultados.

## Relação da análise com o projeto LifeSync

A análise dos dados do IBGE foi utilizada como uma contextualização socioeconômica complementar ao projeto LifeSync.

Por meio dos indicadores de pobreza multidimensional, educação, moradia, saúde, acesso a serviços públicos e outras dimensões, foi possível observar diferenças nas condições de vida entre as Unidades da Federação brasileiras.

Essas informações contribuem para ampliar a compreensão sobre as diferentes realidades socioeconômicas da população, oferecendo uma perspectiva complementar para a discussão do público-alvo e do contexto social em que uma solução de organização pessoal e controle financeiro poderia ser utilizada.

É importante destacar que os indicadores analisados não medem diretamente a organização pessoal ou financeira dos indivíduos e não comprovam a eficácia das funcionalidades propostas pelo LifeSync.
