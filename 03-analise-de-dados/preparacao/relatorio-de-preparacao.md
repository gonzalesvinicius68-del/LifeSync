# Relatório de Preparação dos Dados

## 1. Objetivo

Organizar os dados da Tabela 6b do IBGE para permitir a análise da proporção de pessoas com algum grau de pobreza nas Unidades da Federação brasileiras.

## 2. Fonte dos dados

Os dados foram obtidos do Instituto Brasileiro de Geografia e Estatística (IBGE), no conjunto de tabelas sobre a evolução dos indicadores não monetários de pobreza e qualidade de vida no Brasil, referente ao período de 2017–2018.

## 3. Preparação realizada

- Identificação da Tabela 6b como base para a análise.
- Organização dos nomes das colunas para facilitar a leitura.
- Ordenação das Unidades da Federação pela proporção de pessoas com algum grau de pobreza, do maior para o menor.
- Criação de um gráfico para comparar os percentuais entre os estados.
- Preservação da tabela original como referência para conferência.

## 4. Observações iniciais

Na tabela analisada, Maranhão apresentou a maior proporção de pessoas com algum grau de pobreza, com 58,1%, seguido pelo Pará, com 52,0%, e pelo Acre, com 48,4%.

Entre os menores valores estão Santa Catarina, com 5,1%, Paraná, com 8,7%, e São Paulo, com 9,2%.

Esses resultados descrevem os dados do período de 2017–2018 e não devem ser interpretados como retrato da situação atual.

## 5. Próximas etapas

- Conferir os dados e o gráfico.
- Analisar as diferenças entre as Unidades da Federação.
- Investigar a contribuição das dimensões que compõem o IPM-NM.
- Registrar as conclusões da análise.
