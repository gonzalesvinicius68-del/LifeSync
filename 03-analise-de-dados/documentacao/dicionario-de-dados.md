# Dicionário de Dados — Tabela 6b

## 1. Identificação

- **Fonte:** Instituto Brasileiro de Geografia e Estatística (IBGE).
- **Tabela:** Tabela 6b.
- **Período de referência:** 2017–2018.
- **Tema:** Pobreza multidimensional e qualidade de vida no Brasil.

## 2. Descrição das variáveis

| Variável | Descrição | Unidade |
|---|---|---|
| Unidade da Federação | Nome do estado ou do Distrito Federal ao qual os dados se referem. A tabela também inclui o Brasil. | Categoria geográfica |
| Proporção de pessoas das famílias residentes (%) | Participação das pessoas das famílias residentes na distribuição apresentada pelo IBGE para cada Unidade da Federação. | Percentual (%) |
| Proporção de pessoas com algum grau de pobreza (%) | Percentual de pessoas classificadas com algum grau de pobreza, segundo os critérios do indicador utilizado pelo IBGE. | Percentual (%) |
| IPM-NM | Índice de Pobreza Multidimensional Não Monetária. | Índice |
| Contribuição — Moradia (%) | Contribuição da dimensão moradia para o total dos efeitos marginais no IPM-NM. | Percentual (%) |
| Contribuição — Acesso aos serviços de utilidade pública (%) | Contribuição do acesso aos serviços de utilidade pública para o total dos efeitos marginais no IPM-NM. | Percentual (%) |
| Contribuição — Saúde e alimentação (%) | Contribuição da dimensão saúde e alimentação para o total dos efeitos marginais no IPM-NM. | Percentual (%) |
| Contribuição — Educação (%) | Contribuição da dimensão educação para o total dos efeitos marginais no IPM-NM. | Percentual (%) |
| Contribuição — Acesso a serviços financeiros e padrão de vida (%) | Contribuição dessa dimensão para o total dos efeitos marginais no IPM-NM. | Percentual (%) |
| Contribuição — Transporte e lazer (%) | Contribuição da dimensão transporte e lazer para o total dos efeitos marginais no IPM-NM. | Percentual (%) |

## 3. Observações sobre os dados

- Cada linha representa uma Unidade da Federação, exceto a linha Brasil, que apresenta o resultado nacional.
- Os valores percentuais devem ser interpretados conforme a definição de cada variável.
- As contribuições das dimensões se referem ao total dos efeitos marginais no IPM-NM, conforme o título da tabela original.
- A ordenação da tabela por proporção de pessoas com algum grau de pobreza não altera os valores registrados.
- Os dados correspondem ao período de referência 2017–2018 e não representam necessariamente a situação atual.
