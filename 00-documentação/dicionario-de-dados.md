# Dicionário de Dados — Tabela 6b

## 1. Identificação

- **Fonte:** Instituto Brasileiro de Geografia e Estatística (IBGE).
- **Tabela:** Tabela 6b.
- **Período de referência:** 2017–2018.
- **Tema:** Pobreza multidimensional e qualidade de vida no Brasil.

## 2. Descrição das variáveis

| Variável | Descrição | Unidade |
|---|---|---|
| Unidades da Federação | Identificação do estado, Distrito Federal ou Brasil. | Categoria geográfica |
| Proporção de pessoas das famílias residentes (%) | Participação das pessoas das famílias residentes de cada Unidade da Federação no total nacional. | Percentual (%) |
| Proporção de pessoas com algum grau de pobreza (%) | Percentual de pessoas com algum grau de pobreza, segundo os critérios do indicador utilizado pelo IBGE. | Percentual (%) |
| IPM-NM | Índice de Pobreza Multidimensional Não Monetário. | Índice |
| Contribuição — Moradia (%) | Contribuição da dimensão moradia para o total dos efeitos marginais no IPM-NM. | Percentual (%) |
| Contribuição — Acesso aos serviços de utilidade pública (%) | Contribuição dessa dimensão para o total dos efeitos marginais no IPM-NM. | Percentual (%) |
| Contribuição — Saúde e alimentação (%) | Contribuição dessa dimensão para o total dos efeitos marginais no IPM-NM. | Percentual (%) |
| Contribuição — Educação (%) | Contribuição dessa dimensão para o total dos efeitos marginais no IPM-NM. | Percentual (%) |
| Contribuição — Acesso a serviços financeiros e padrão de vida (%) | Contribuição dessa dimensão para o total dos efeitos marginais no IPM-NM. | Percentual (%) |
| Contribuição — Transporte e lazer (%) | Contribuição dessa dimensão para o total dos efeitos marginais no IPM-NM. | Percentual (%) |

## 3. Observações sobre os dados

- Cada linha representa uma Unidade da Federação, exceto a linha Brasil, que apresenta o resultado nacional.
- Os valores percentuais devem ser interpretados conforme a definição de cada variável.
- As contribuições das dimensões representam a participação de cada uma no total dos efeitos marginais do IPM-NM.
- A ordenação da tabela pela proporção de pessoas com algum grau de pobreza não altera os valores registrados.
- Os dados são referentes ao período de 2017–2018 e não representam necessariamente a situação atual.
