# Fonte dos Dados — LifeSync

## 1. Identificação da fonte

- **Instituição responsável:** Instituto Brasileiro de Geografia e Estatística (IBGE).
- **Conjunto de dados:** Evolução dos Indicadores Não Monetários de Pobreza e Qualidade de Vida no Brasil.
- **Período de referência:** 2017–2018.
- **Arquivo utilizado:** Tabela 6b.
- **Formato original:** Excel (.xlsx).
- **Origem:** Dados reais e públicos.

## 2. Descrição dos dados

A Tabela 6b apresenta informações sobre a proporção de pessoas das famílias residentes, a proporção de pessoas com algum grau de pobreza, o IPM-NM e as contribuições das seis dimensões para o total dos efeitos marginais do índice, segundo as Unidades da Federação.

## 3. Objetivo da análise

Investigar como a proporção de pessoas com algum grau de pobreza varia entre as Unidades da Federação e analisar as contribuições das seis dimensões consideradas no IPM-NM.

## 4. Link da fonte

Instituto Brasileiro de Geografia e Estatística (IBGE):

https://ftp.ibge.gov.br/Orcamentos_Familiares/Evolucao_dos_Indicadores_nao_Monetarios_de_Pobreza_e_Qualidade_de_Vida_no_Brasil/tabelas_2017_2018_xls.zip

## 5. Tratamento realizado

A tabela original foi organizada para facilitar a análise dos dados.

Os procedimentos realizados incluíram:

- Padronização dos nomes das colunas.
- Organização das informações em uma planilha tratada.
- Ordenação das Unidades da Federação pela proporção de pessoas com algum grau de pobreza, do maior para o menor.
- Preservação da linha Brasil para representar os resultados nacionais.
- Preparação dos dados para elaboração de gráficos e comparações.

**Observação:** a organização e a ordenação dos dados não alteram os valores originais disponibilizados pelo IBGE.
