Gestão de Projetos — LifeSync

1. Apresentação

Esta seção reúne o planejamento do projeto acadêmico LifeSync, incluindo a definição dos objetivos, a delimitação do escopo, a organização das atividades e o acompanhamento das entregas.

2. Documentos previstos

Termo de Abertura do Projeto (TAP).

Estrutura Analítica do Projeto (EAP).

Cronograma de atividades (Gantt).

Matriz de responsabilidades (RACI).

Matriz de riscos.

Estimativa de custos.

3. Objetivo da disciplina

Aplicar práticas de gestão de projetos para planejar, organizar e acompanhar as entregas do LifeSync, considerando o prazo acadêmico, os recursos disponíveis, as responsabilidades da equipe e os riscos envolvidos.

4. Situação dos documentos

Os documentos serão elaborados e revisados progressivamente durante o desenvolvimento do projeto. A inclusão nesta lista não significa que todos já estejam concluídos.
