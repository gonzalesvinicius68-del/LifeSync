Pesquisa Operacional — LifeSync

Esta seção reunirá os modelos matemáticos, os dados de entrada, os notebooks Python e os relatórios de resultados da Pesquisa Operacional.

Serão desenvolvidos dois problemas de otimização: um de maximização de lucro com restrições e outro de minimização de custos de transporte ou atribuição.

Os modelos serão implementados em Python no Google Colab, utilizando bibliotecas apropriadas de otimização, com análise de cenários e interpretação crítica dos resultados.
