Registros de Reuniões — LifeSync

Objetivo

Registrar as reuniões da equipe durante o desenvolvimento do projeto acadêmico LifeSync.

Informações a registrar

Cada ata deverá conter, quando aplicável:

Data e horário da reunião.

Participantes presentes.

Pauta discutida.

Decisões tomadas.

Tarefas definidas e respectivos responsáveis.

Pendências para a próxima reunião.

Orientações

Os registros devem refletir reuniões e decisões que realmente ocorreram. Não preencher atas fictícias como se fossem reuniões realizadas.

Evitar publicar dados pessoais desnecessários.

Status
